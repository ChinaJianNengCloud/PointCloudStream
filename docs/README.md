# PointCloudStream 中文技术文档

PointCloudStream 将多相机观测、标定板定位、机械臂示教和轨迹采集组织在一个桌面工作台中，并提供独立的点云标注与数据整理工具。其技术核心是把图像、空间位姿、运动指令和训练样本之间的关系连接起来。

当前桌面入口以多路 RGB 图像和机械臂数据为中心。点云投影、几何分割及 VTK 点云浏览位于独立工具链中，没有接入主窗口的实时处理循环。各模块的接口边界和现有兼容性限制见对应章节。

## 阅读路径

- 接入相机或排查采样问题：系统架构 → 多相机采集 → 示教数据。
- 修改标定板跟随：相机标定 → 位姿表示 → 机械臂控制。
- 接入外部模型服务：Agent 协议 → 位姿表示 → 机械臂控制。
- 处理历史点云或训练数据：点云算法 → 离线数据整理 → 示教数据格式。

## 术语与约定

| 术语 | 含义 |
| --- | --- |
| TCP | 机械臂工具中心点；在网络章节中，TCP 指传输控制协议，由上下文区分 |
| Episode | 由一段任务文本及其示教点、回放记录和图像引用组成的数据记录 |
| 关键点 | 人工采集的离散 TCP 位姿与关节位置 |
| 录制帧 | 回放期间采样的机器人状态和各相机图像引用 |
| `control` | 主程序约定的标定与跟随相机名称，具有特殊处理逻辑 |
| `segment_id` | PLY 中的标签字段；含义由具体算法决定，可能是语义类别或几何区域编号 |
| `T_A_B` | 将 B 坐标系中的坐标转换到 A 坐标系的齐次变换 |

机器人 TCP 位姿的数组顺序统一写作 `[x, y, z, rx, ry, rz]`。当前控制链使用米和弧度；历史文本位姿文件使用毫米和角度，转换发生在读取边界。旋转向量、欧拉角和四元数不能仅凭数组长度互换。

## 文档范围

各章节围绕算法、并发、控制和数据一致性展开。普通控件布局、聊天气泡样式、数据树展示和日志封装不单独展开。源码链接指向相关实现，函数名称用于定位具体机制。

模块中保留的入口、按钮和参数不一定构成完整可运行流程。[系统架构与运行边界](architecture.md)集中说明配置来源与模块兼容性；各专题进一步解释其对数据和算法的影响。
